🛡️ CyberGuard AI — Intrusion Detection System

📌 Overview

CyberGuard AI is a machine learning based Intrusion Detection System (IDS) that analyzes network traffic and detects whether the traffic is Normal or Attack.

The project uses the CICIDS2017 dataset and a Random Forest machine learning model to identify malicious network traffic.

🎯 Objectives

- Analyze network traffic data
- Clean and preprocess the dataset
- Identify different attack types
- Analyze important network features
- Train a machine learning model
- Evaluate model performance
- Detect Normal and Attack traffic

🗂️ Dataset

CICIDS2017

The dataset contains realistic network traffic with both benign and different types of cyber attacks.
